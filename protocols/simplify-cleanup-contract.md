# Simplify Cleanup Contract

t-simplify 的审查角度、finding 结构、去重/跳过/修复边界和报告结构的单一事实源。复刻来源见 `skills/t-simplify/SKILL.md` 的来源说明。

本契约只做代码质量清理，不找正确性缺陷；正确性缺陷属于 `/code-review` 与各阶段 accept 的职责。

## Review Angles

四个角度互不重叠，每个 reviewer agent 只负责注入的一个角度：

### Reuse（复用）

- diff 内部重复：同一段逻辑、校验或组装在多个位置复制粘贴，应提取为共享 helper。
- 与既有代码重复：新代码重新实现了项目里已经存在的工具函数、组件、hook、常量或配置；优先复用既有实现。
- 应参数化而非复制的分支：多个分支只有少数字面量不同，应收敛为带参数的单份实现。
- 重复的样板：可用既有宏、派生、装饰器或项目封装消除的模板代码。

### Simplification（简化）

- 不必要的抽象：只有一个调用方、只有一个实现或只被测试使用的间接层；优先展开为直接实现。
- 过度防御：对不可能为空的值反复解包守卫、对内部可信输入做冗余校验。
- 冗余分支与死代码：永假条件、重复 return、被上游已排除的错误分支。
- 可声明化的命令式逻辑：可用语言内置结构（迭代器、模式匹配、comprehension、配置表驱动）替代的手写循环与状态机。
- 命名与结构噪音：多层嵌套可早返回拉平、超长表达式可命名、误导性命名。

### Efficiency（效率）

- 冗余计算或重复 I/O：循环内重复求值、重复序列化/反序列化、同一数据多次查询。
- 可合并的串行操作：独立网络请求或查询逐个 await，可并发或批量。
- 热路径上的阻塞工作：启动路径、请求路径上新增的同步重活。
- 前端特有：不必要的重渲染、缺失的 memo/依赖收敛、在 render 中重建大对象。
- 每条发现必须指出更便宜的替代做法。

### Altitude（抽象层级）

- 修改是否做在正确深度：在共享机制上叠特例（特殊参数、旁路分支）通常是修得太浅；优先泛化底层机制而非新增特例。
- 层级错放：领域逻辑漏进 HTTP handler/组件，基础设施细节漏进领域层。
- 特例累积信号：同一共享函数上已有多处调用点特判，本次 diff 又新增一处。
- 泄漏的实现细节：调用方依赖被调方的内部表示（字段名、错误码字面量、内部状态）。

## Finding Structure

每个 reviewer 按以下结构返回 findings：

```text
findings:
  - file:
    line:
    summary:          # 单行结论
    cost:             # 具体代价：什么被重复、浪费或更难维护
    fix_hint:         # 建议修法（可选）
```

- `file`/`line` 指向本次 diff 范围内的位置；找不到精确行号时给最近的可定位位置。
- `cost` 必须具体可评估；写不出具体代价的发现不返回。
- reviewer 只读，不修改代码。

## Dedup

主流程聚合全部 findings 后：

- 指向同一行或同一机制的发现合并为一条，保留描述最具体的一条，角度标记合并。
- 仅描述风格差异、不构成独立代价的发现合并。

## Skip Rules

修复前逐条判断，以下三类跳过并在报告中记录原因，不与发现争论：

1. 修复会改变预期行为（对外语义、输出、错误路径）。
2. 修复需要明显超出本次审查 diff 的改动。允许的例外：为消除重复新建共享 helper 文件，并让 diff 内代码改用它；但不得修改 diff 外已有文件的既有逻辑。
3. 判定为误报。

## Report

写入 `.ai/quality/simplify-[YYYYMMDD-HHMMSS].md`：

```text
# Simplify 报告 [YYYYMMDD-HHMMSS]

## 审查范围
- diff 来源: git diff HEAD | 最近修改文件
- 文件数 / 变更行数
- focus（如有）

## 修复的发现
- file:line | 角度 | summary | 修复说明

## 跳过的发现
- file:line | 角度 | summary | 跳过原因（行为变化 | 超出范围 | 误报）

## 结论
- 已修复 N 项，跳过 M 项；或代码已干净
```

inline 降级模式（Agent tool 不可用）的报告必须在结论中声明：这是单主会话单遍审查，不是 4-agent 并行审查，读者不应对审查强度产生误判。
